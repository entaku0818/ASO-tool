### 1-3. エラー状態の設計

| エラー種別 | 表示場所 | 表示内容 | 消えるタイミング |
|-----------|---------|---------|----------------|
| 画像未アップロード | textarea 直下 | `⚠️ 先に画像をアップロードしてください` (amber) | 画像アップ or 3秒後 |
| API タイムアウト | textarea 直下 | `⏱ タイムアウトしました。もう一度お試しください` (red) | 再生成クリック or 5秒後 |
| API エラー（5xx） | textarea 直下 | `✗ 生成に失敗しました。しばらくしてから再試行してください` (red) | 再生成クリック or 5秒後 |
| 候補ゼロ件 | 候補エリア | `候補が生成されませんでした。キャプションを手動で入力してください` (gray) | キャンセルクリック |

**表示スタイル**: エラーはすべて `text-sm rounded-lg px-3 py-2` のインラインバナー。モーダルは使わない（ユーザーを作業フローから離脱させない）。

---

### 1-4. Pro / Free 制御

| プラン | 動作 |
|-------|------|
| Free | 現在選択中の言語のみ生成（1言語） |
| Pro | 全6言語を一括生成し、言語タブごとに候補を自動セット |

Free ユーザーが全言語生成を試みた場合 → UpgradeModal を `triggerFeature="AI一括キャプション生成"` で表示。

### 2-4. エンジニアへの実装メモ

- シェアカードは `<canvas>` で生成（ScreenshotGenerator の `drawFrame` の仕組みを流用可能）
- `canvas.toBlob()` → `navigator.clipboard.write()` で画像コピー対応
- X シェアは `https://twitter.com/intent/tweet?text=...&url=...` の URL スキーム
- 順位上昇の検知: `useRankingHistory` の結果を前回比較 → `previousRank - currentRank >= 5` で判定

### 3-3. エラー種別と表示コピー

| エラー種別 | 表示コピー | 追加アクション |
|-----------|----------|--------------|
| ネットワーク断 | `インターネット接続を確認してから再度お試しください` | なし |
| サーバーエラー (5xx) | `決済ページへの接続に失敗しました。しばらくしてから再度お試しください` | サポートリンク |
| 認証エラー (401) | `セッションが切れました。再ログインしてからお試しください` | ログインページへリンク |
| 不明なエラー | `エラーが発生しました。もう一度お試しください` | サポートリンク |

### 3-4. ステート設計（エンジニア向け）

```tsx
// 追加するステート
const [checkoutError, setCheckoutError] = useState<string | null>(null)

// handleUpgrade の catch 内
} catch (err) {
  const msg = err instanceof Error && err.message.includes('401')
    ? 'セッションが切れました。再ログインしてからお試しください'
    : 'エラーが発生しました。もう一度お試しください'
  setCheckoutError(msg)
  setIsLoading(false)
}

// モーダルが閉じたらリセット
// isOpen が false になったら checkoutError も null に

// CTAボタンテキスト
{isLoading ? '処理中...' : checkoutError ? 'もう一度試す' : '7日間 無料トライアルを開始'}
```

### 3-5. 表示タイミング・消え方

| タイミング | 動作 |
|-----------|------|
| エラー発生直後 | エラーバナーを CTAボタン上部に表示 |
| 「もう一度試す」クリック | `setCheckoutError(null)` → バナー消去 → 再リクエスト |
| モーダルを閉じる | `setCheckoutError(null)` → リセット |
| Escape キー | 同上 |

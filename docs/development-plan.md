## プロジェクト概要

**ASO-tool** は App Store Optimization のための Web アプリケーションです。

### 主要機能

| 機能 | 説明 |
|------|------|
| キーワードランキング追跡 | 指定キーワードでの検索順位を定期的に記録 |
| レビュー監視 | App Store レビューの新着監視と分析 |
| 競合分析 | 競合アプリとのランキング比較 |

### 対象ユーザー

- アプリ開発者
- マーケティング担当者
- プロダクトマネージャー

## 機能一覧

### アプリ管理

```
機能: アプリ登録・編集・削除
エンドポイント:
  - GET    /api/apps      → アプリ一覧取得
  - POST   /api/apps      → アプリ登録
  - GET    /api/apps/:id  → アプリ詳細取得
  - PUT    /api/apps/:id  → アプリ更新
  - DELETE /api/apps/:id  → アプリ削除
```

### キーワード管理

```
機能: 監視キーワードの設定
エンドポイント:
  - GET    /api/apps/:id/keywords     → キーワード一覧
  - POST   /api/apps/:id/keywords     → キーワード追加
  - DELETE /api/apps/:id/keywords/:kw → キーワード削除
```

### ランキング取得

```
機能: App Store 検索ランキングの取得・保存
エンドポイント:
  - GET  /api/apps/:id/rankings           → ランキング履歴
  - POST /api/apps/:id/rankings/fetch     → ランキング取得実行
```

### レビュー監視

```
機能: App Store レビューの取得・表示
エンドポイント:
  - GET  /api/apps/:id/reviews            → レビュー一覧
  - POST /api/apps/:id/reviews/fetch      → レビュー取得実行
```

### 競合比較

```
機能: 競合アプリの順位追跡・比較
エンドポイント:
  - GET    /api/apps/:id/competitors              → 競合アプリ一覧
  - POST   /api/apps/:id/competitors              → 競合アプリ追加
  - GET    /api/apps/:id/competitors/:cid         → 競合アプリ詳細
  - DELETE /api/apps/:id/competitors/:cid         → 競合アプリ削除
  - POST   /api/apps/:id/competitors/update-rankings → 競合順位更新
  - GET    /api/apps/:id/keywords/:kwid/comparison   → 順位比較データ
```

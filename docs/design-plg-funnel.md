## 1. UpgradeModal 改善案

### 1-1. 表示タイミング（トリガー設計）

| トリガー | 発火条件 | subhead コピー |
|---------|---------|--------------|
| アプリ上限 | Free ユーザーが 2 本目のアプリを追加しようとしたとき | 「複数アプリをまとめて管理するには Pro が必要です」 |
| CSV エクスポート | Free ユーザーが CSV ダウンロードボタンを押したとき | 「CSV エクスポートは Pro プランの機能です」 |
| 競合逆引き | Free ユーザーが競合キーワードタブを開こうとしたとき | 「競合キーワード逆引きは Pro プランの機能です」 |
| 一括スクショ | Free ユーザーが 2 言語目以降を選択しようとしたとき | 「多言語スクリーンショット一括生成は Pro プランの機能です」 |
| 軟直誘導（Soft） | Activation 完了後（初回キーワード登録 3 件達成） | 「順位チェックを始めたら、次は競合を分析しましょう」 |

**原則**: ハードブロック（機能を完全に止める）より、ソフト誘導（使えることを見せてから促す）を優先する。  
Soft トリガーは週 1 回のみ発火（localStorage で管理）。

### 1-3. コピー案（文言）

**ヘッドライン**: `Pro にアップグレード`（変更なし。シンプルで明快）

**サブヘッド（トリガー別）**:
- アプリ上限: `複数アプリを一元管理して、ASO 戦略を加速させましょう`
- 競合逆引き: `競合アプリの上位キーワードをリスト化して、勝てる施策を見つけましょう`
- CSV: `データをエクスポートして、チームと共有しましょう`
- Soft: `順位チェックの次は、競合分析でもっと深く掘り下げましょう`

**CTA ボタン**: `7日間 無料トライアルを開始`（強調: 無料 / リスクなし）

**スキップリンク**: `今は無料のまま使う（いつでも変更可）`

### 2-2. 発火条件・除外条件

| 条件 | 内容 |
|------|------|
| 発火 | `user.created_at` から 72 時間以内 **かつ** アプリ登録数 = 0 |
| 発火（途中再開） | Step 2 完了済み・Step 3 未完了の場合は Step 3 から再開 |
| 除外 | localStorage に `onboarding_completed: true` が存在する場合 |
| スキップ後 | スキップしても 24 時間後に Step 1 のバナーを Header 下に表示（1 回のみ） |

### 2-3. Activation の定義

**Activation = キーワード 3 件以上登録 + 初回順位データ受信**

- この状態に到達したユーザーを「Activated ユーザー」として計測
- Activated ユーザーへの UpgradeModal は「Soft トリガー」で週 1 回のみ表示

## エンジニア連携ポイント

| 機能 | 必要な対応 | 優先度 |
|------|----------|--------|
| オンボーディングフロー | `users` テーブルに `onboarding_completed BOOLEAN` カラム追加 or フロントのみで localStorage 管理 | High |
| テンプレートライブラリ | `templates` テーブル（id, name, category, thumbnail_url, is_pro） + API エンドポイント | Medium |
| UpgradeModal 年払いラジオ | フロントのみ対応可（`handleUpgrade('yearly')` は実装済み） | High（即対応可） |
